# Getting Started with Prompt Sanctuary

Welcome to Prompt Sanctuary! This guide will help you set up your account and start generating powerful AI prompts.

## What is Prompt Sanctuary?

Prompt Sanctuary is a comprehensive platform for creating, managing, and optimizing AI prompts. Whether you're a beginner or an expert in prompt engineering, our platform provides the tools you need to create effective prompts that generate better AI responses.

### Key Benefits
- **AI-Powered Generation**: Create prompts using advanced AI models
- **Smart Optimization**: Get suggestions to improve your prompts
- **Version Control**: Track changes and restore previous versions
- **Community Sharing**: Share and discover prompts from other users
- **Economy System**: Earn points and unlock achievements
- **Multilingual Support**: Use in English or Indonesian

## Creating Your Account

### 1. Registration
1. Visit the [Prompt Sanctuary website](https://sanctuary01.pythonanywhere.com/)
2. Click "Sign Up" in the top navigation
3. Choose a unique username
4. Create a secure password
5. Optionally provide an email address for account recovery

### 2. First Login
1. Click "Login" and enter your credentials
2. You'll start with 80 points to generate prompts
3. Complete your profile setup if desired

## Understanding the Interface

### Main Navigation
- **Home**: Dashboard with quick access to all features
- **Generate**: Create new prompts with AI assistance
- **Advance**: Advanced prompt generation with custom parameters
- **Library**: Browse community-shared prompts
- **My Library**: Access your saved prompts
- **Profile**: Manage your account and settings

### Sidebar Features
- **Points Display**: Shows your current point balance (click to view history)
- **Language Switcher**: Switch between English and Indonesian
- **API Key Status**: Shows if you're using a personal API key
- **Notifications**: Achievement unlocks and system messages

## Your First Prompt

### Basic Text Generation
1. Navigate to **Generate** from the main menu
2. Type your prompt idea in the text box
3. Watch the character counter and refinement suggestions
4. Click **Generate** to create your prompt
5. Review the AI-generated result
6. Save it to your personal library if you like it

### Understanding Point Costs
Different prompt types have different costs:
- **Basic Text**: 1.5 points
- **Basic Random**: 0.8 points
- **Advanced Text**: 1.9 points
- **Advanced Image**: 1.9 points

*Tip: Using your own API key eliminates point costs!*

## Earning Points

### Daily Login Bonus
- Log in daily to earn 5-12 random points
- Consistent daily logins unlock streak achievements

### Achievements
Unlock achievements by:
- Generating prompts
- Saving prompts to your library
- Sharing prompts with the community
- Using advanced features
- Maintaining login streaks

### API Key Contribution
- Add your own Gemini API key to earn 100 bonus points
- Your key helps the community and earns you compensation
- No point deduction when using your own key

## Basic Features Walkthrough

### Prompt Refinement
1. Type a prompt that's too short or too long
2. See the refinement suggestions appear
3. Click "Elaborate" to add more detail
4. Click "Shorten" to make it more concise
5. The AI will optimize your prompt automatically

### Saving Prompts
1. After generating a prompt you like, click "Save"
2. Give it a descriptive title
3. Add tags for better organization
4. Choose whether to share with the community
5. Access saved prompts in "My Library"

### Version Control
1. Edit any saved prompt
2. The system automatically creates a new version
3. Click "History" to view all versions
4. Restore any previous version if needed

### Community Features
1. Browse the community library for inspiration
2. Copy prompts you find useful
3. Share your own prompts to help others
4. Use tags and search to find specific types of prompts

## Tips for Success

### Writing Better Prompts
1. **Be Specific**: Include details about what you want
2. **Use Examples**: Provide sample inputs and desired outputs
3. **Set Context**: Explain the situation or domain
4. **Define Format**: Specify how you want the response formatted
5. **Iterate**: Use refinement suggestions to improve

### Managing Your Library
1. **Use Descriptive Titles**: Make prompts easy to find
2. **Add Tags**: Organize by topic, use case, or domain
3. **Regular Cleanup**: Remove outdated or unused prompts
4. **Share Good Prompts**: Help the community grow

### Optimizing Point Usage
1. **Add Your API Key**: Eliminate point costs
2. **Use Refinement Wisely**: Only refine when necessary
3. **Login Daily**: Earn bonus points consistently
4. **Unlock Achievements**: Get point rewards for milestones

### Common Questions

**Q: Why do I need points to generate prompts?**
A: Points help manage API costs and encourage thoughtful prompt creation. You can eliminate costs by adding your own API key.

**Q: Can I use Prompt Sanctuary without an account?**
A: No, an account is required to save prompts and access community features. Registration is free and quick.

**Q: What if I run out of points?**
A: You can earn points through daily logins, achievements, or by adding your own API key. Points reset and expire over time.

**Q: Is my data secure?**
A: Yes, we use industry-standard security practices including CSRF protection, input sanitization, and secure session management.
