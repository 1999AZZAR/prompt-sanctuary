# API Key Setup Guide

This guide will help you set up your Gemini API key to use Prompt Sanctuary. API keys are required to generate prompts and use all features of the application.

## Getting Your Gemini API Key

### Step 1: Visit Google AI Studio

1. Go to [Google AI Studio](https://aistudio.google.com/)
2. Sign in with your Google account
3. If you don't have a Google account, create one first

### Step 2: Create an API Key

1. In Google AI Studio, click on "Get API Key" in the left sidebar
2. Click "Create API Key in new project" or select an existing project
3. Choose your Google Cloud project (or create a new one)
4. Copy the generated API key (it will start with "AI")

### Step 3: Set Up Billing (Required)

**Important**: Gemini API requires a billing account to work properly.

1. Go to [Google Cloud Console](https://console.cloud.google.com/)
2. Select your project
3. Go to "Billing" in the left menu
4. Link a billing account to your project
5. Add a payment method (credit card)

**Note**: Gemini API has a free tier with generous limits, so you likely won't be charged for normal usage.

## Adding Your API Key to Prompt Sanctuary

### Step 1: Log In to Prompt Sanctuary

1. Go to your Prompt Sanctuary account
2. Log in with your username and password

### Step 2: Navigate to API Key Settings

1. Click on your profile/account settings
2. Look for "API Key Management" or "API Settings"
3. You'll be redirected to the API key setup page if you haven't added one yet

### Step 3: Enter and Validate Your API Key

1. Paste your Gemini API key in the input field
2. Click "Validate" to test your key
3. Wait for validation to complete
4. If successful, your key will be saved automatically

## Troubleshooting Common Issues

### "Invalid API key format"
- Make sure your API key starts with "AI"
- Check that you copied the entire key
- Ensure there are no extra spaces

### "API key quota exceeded"
- You may have reached your daily/monthly limits
- Check your usage in Google Cloud Console
- Wait for quota to reset or upgrade your plan

### "Billing account required"
- You need to set up billing in Google Cloud Console
- Link a payment method to your project
- This is required even for free tier usage

### "API key lacks required permissions"
- Ensure your API key has Gemini API access
- Check that the API is enabled in your Google Cloud project
- Try creating a new API key

### "API not available in your region"
- Gemini API may not be available in all regions
- Try using a VPN or contact support
- Check Google's service availability page

## Security Best Practices

### Keep Your API Key Secure

1. **Never share your API key** with others
2. **Don't post it publicly** on forums or social media
3. **Use environment variables** if you're a developer
4. **Rotate your keys regularly** for security

### Monitor Your Usage

1. Check your API usage in Google Cloud Console
2. Set up billing alerts to avoid unexpected charges
3. Monitor your quota usage regularly

### If Your Key is Compromised

1. **Immediately revoke the key** in Google Cloud Console
2. **Create a new API key** to replace it
3. **Update your Prompt Sanctuary account** with the new key
4. **Review your usage logs** for any unauthorized activity

## API Key Management

### Updating Your API Key

1. Go to your API key settings in Prompt Sanctuary
2. Enter your new API key
3. Click "Validate" to test it
4. Save the changes

### Removing Your API Key

1. Go to API key settings
2. Click "Remove API Key"
3. Confirm the removal
4. You'll need to add a new key to continue using the service
